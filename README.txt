工时打卡 PWA 安装说明
====================

一、部署到网上（免费，任选其一）
1. GitHub Pages：新建仓库 → 上传这几个文件 → Settings → Pages → 选 main 分支
2. Vercel / Netlify：把本文件夹整个拖进去即可
3. 部署后得到一个 https 地址（例如 https://xxx.github.io/workclock）

二、iPhone 上安装
1. 用 Safari 打开这个 https 地址
2. 点底部分享按钮（方块箭头）
3. 选「添加到主屏幕」
4. 主屏幕上就会出现「工时打卡」图标，点开全屏使用，离线也能打卡

注意：
- 数据保存在本机浏览器里，清浏览器数据会清掉记录
- 支持深色模式，跟着系统自动切换
